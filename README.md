<h1>📱 WHMCS Mobile Browser Tab Color</h1>

<p>
The <strong>WHMCS Mobile Browser Tab Color Addon</strong> allows you to set a custom color for the browser tab on supported mobile devices.<br>
It provides a native-app feel to your WHMCS client area without requiring any template modifications.
</p>

<hr>

<h2>✨ Features</h2>
<ul>
  <li>Works with <strong>WHMCS 7.x &amp; 8.x</strong></li>
  <li>Set your preferred mobile browser tab color</li>
  <li>No template changes required</li>
  <li>Compatible with any WHMCS template</li>
  <li>Lightweight &amp; simple installation</li>
</ul>

<hr>

<h2>📥 Installation</h2>
<ol>
  <li>Download the latest release package.</li>
  <li>Unzip the downloaded file and upload the folder <code>mobiletabcolor/</code> to:<br>
    <pre>YOUR_WHMCS_ROOT/modules/addons/</pre>
  </li>
  <li>Login to your WHMCS Admin → <strong>System Settings → Addon Modules</strong>.</li>
  <li>Activate <strong>Mobile Browser Tab Color</strong> addon.</li>
</ol>

<hr>

<h2>⚙️ Usage</h2>
<ol>
  <li>In WHMCS Admin, go to <strong>Addons → Mobile Browser Tab Color</strong>.</li>
  <li>Select your preferred color.</li>
  <li>Save and check your WHMCS client area on a mobile device.</li>
</ol>

<hr>

<h2>📂 Folder Structure</h2>
<pre>
YOUR_WHMCS_ROOT/
└── modules/
    └── addons/
        └── mobiletabcolor/
            ├── mobiletabcolor.php
            ├── hooks.php
            ├── index.php
            ├── whmcs.json
            └── logo.png
</pre>
